🦖 Dino Charge - Offline Chrome Dino Game

A C++ implementation of the classic Chrome offline dinosaur game. Play the beloved dinosaur runner right on your desktop!


🎮 Overview

Dino Charge is a desktop game built in C++ that recreates the iconic Chrome dinosaur game that appears when you lose internet connection. This project brings the fun of the offline game to your desktop with the same addictive gameplay you love.

✨ Features

Classic Gameplay: Jump over cacti and avoid obstacles
Offline Play: Play anytime without internet connection
Score Tracking: Keep track of your high scores
Smooth Animation: Fluid graphics and responsive controls
Easy Controls: Simple keyboard controls for accessibility

🎯 How to Play

Start the Game: Run DinoRunner.exe
Jump: Press SPACE or UP ARROW to make the dinosaur jump
Avoid Obstacles: Jump over cacti and other obstacles
Increase Score: The longer you survive, the higher your score
Game Over: Hit an obstacle and the game ends
Restart: Press SPACE to start a new game
